
# 🇻🇳 Hương Vị Việt – Khám phá món ăn nổi tiếng tại Việt Nam

Website giới thiệu những món ăn nổi tiếng của Việt Nam, giúp người xem khám phá nét đặc sắc trong văn hóa ẩm thực ba miền Bắc – Trung – Nam.

## 📌 Giới thiệu dự án

**Hương Vị Việt** là website được xây dựng trong khuôn khổ bài tập Vibe Coding. Website có giao diện hiện đại, thân thiện, tương thích với máy tính và điện thoại.

### 🎯 Mục tiêu
- Giới thiệu các món ăn đặc trưng của Việt Nam.
- Khám phá sự khác biệt trong ẩm thực ba miền.
- Thực hành HTML5, CSS3 và JavaScript.
- Rèn luyện kỹ năng thiết kế website responsive.

## ✨ Tính năng nổi bật

- **Trang chủ:** Giới thiệu chủ đề ẩm thực Việt Nam.
- **Ẩm thực ba miền:** Khám phá đặc trưng của miền Bắc, miền Trung và miền Nam.
- **Danh sách món ăn:** Giới thiệu Phở bò Hà Nội, Bún bò Huế, Bánh mì Sài Gòn và Cơm tấm Sài Gòn.
- **Bộ lọc món ăn:** Lọc món theo từng vùng miền.
- **Giỏ hàng demo:** Thêm món ăn và xem tổng tiền tạm tính.
- **Hiệu ứng chuyển động:** Sử dụng Animate.css và AOS.
- **Responsive:** Tự động điều chỉnh giao diện trên nhiều kích thước màn hình.
- **Đăng ký nhận tin demo:** Hiển thị thông báo khi gửi biểu mẫu.

## 🚀 Cách chạy website

1. Tải hoặc sao chép mã nguồn dự án về máy.
2. Mở thư mục dự án.
3. Mở file `index.html` bằng trình duyệt web.
4. Đảm bảo có kết nối Internet để tải hình ảnh, phông chữ và thư viện hiệu ứng bên ngoài.

Bạn cũng có thể sử dụng tiện ích **Live Server** trong Visual Studio Code để chạy website.

## 🌐 Triển khai website

Có thể sử dụng GitHub Pages để đăng website miễn phí:

1. Tạo repository trên GitHub.
2. Tải `index.html`, `README.md` và `PROMPT_LOG.md` lên repository.
3. Vào **Settings → Pages**.
4. Chọn nhánh `main` và thư mục `/ (root)`.
5. Nhấn **Save** và chờ GitHub Pages triển khai website.

Sau khi triển khai, GitHub sẽ cung cấp đường dẫn website để chia sẻ.
